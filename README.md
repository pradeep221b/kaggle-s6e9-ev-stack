# Kaggle Playground S6E9 — Predicting Electric Vehicle Purchases: the stack

Binary classification, ROC AUC. 668,665 train / 286,571 test rows, 13 features, 17.46% positive, synthetic copy of a
10k-row original that was itself generated by a logistic formula. Competition ran 2026-09-01 to 09-30.

**Result: private LB 0.94558, rank 192 of 3,576 (top 5.4%).** CV 0.94657, public LB 0.94672, 30-member logit stack.

This repo is the stack and nothing else: every member that is in the final submission, the exact parameters that produced it,
the honest cross-validation protocol they all share, and the stacker that combines them. One notebook per model family, with
the explanation of what the model does and why it is in the stack. The dead-end experiments (feature engineering, Optuna,
meta-learners, the generator-form model) are summarised where they changed a decision, not reproduced.

## The protocol every member follows

- **Folds:** `StratifiedKFold(5, shuffle=True, random_state=42)` on the untouched `train.csv`, in file order. Never changed.
  `src/cv.py` is the single source of truth; arrays from any machine merge.
- **Honest OOF:** early stopping on an inner 10% split of the training fold, never on the scored fold. Every label-derived
  feature (target encodings, local rates) is fitted inside the training fold, with inner cross-fitting for the training rows.
- **Test prediction:** 100%-train refit with the mean early-stopped round count x 1.1 (`test_<tag>_full.npy`); the stacker
  prefers it over the fold average.
- **One ruler:** `cv.paired(new, ref, y)` — per-fold AUC differences. REAL if mean > 2 sd and all 5 folds move the same way.
  Noise floor for a paired comparison ~0.00003; unpaired fold spread ~0.0008, so raw fold numbers are never compared.
- **Selection by OOF only.** The public LB (20% of test, s.e. ~0.0005) was never used to pick anything.

## What decided the competition (ours and everyone's)

1. **Exact-value resolution.** Income has 13,214 distinct values and the generator wrote signal into them. `max_bin=13214` +
   additive constraints = +0.0036 in one move. Per-exact-value residual corrections afterwards: <= 0, the tree already extracts
   everything a lookup can.
2. **Strong x different, fitted weights.** A blend partner must be nearly as strong (>= 0.9450) and built differently.
   Weak-but-different models (LR 0.938, GAM 0.939, lookup 0.942) hurt at every weight. Equal rank averaging loses; the
   cross-fitted logistic stacker wins. Nonlinear meta-learners lose (table in notebook 06).
3. **Generator-aware features (heuljax).** Target rates keyed by the GPT-2 BPE tokens of the income string. The rows were almost
   certainly LLM-generated; this feature family was the largest late gain in every top-15 write-up. We added it as borrowed OOF
   columns on the last two days (+0.00036 CV). The top 10 ported the features and trained residual GBDTs on them. That is the
   0.00016 between 192nd and 10th.
4. **Honesty beats cleverness.** Our first replication of the najiama recipe changed four hyper-parameters, scored 0.94500 and was
   filed as dead for a week. Run as published, then made honest: 0.94572 and the biggest stack gain of the first half.

```
pip install -r requirements.txt
kaggle competitions download -c playground-series-s6e9 -p data && unzip data/*.zip -d data

python src/run_stream.py --model lgb --seed 42 --refit   # ~50 min CPU; xgb / cb / tabm / realmlp / ftt likewise
MODEL=cb python src/naji3_stream.py 42                   # ~45 min GPU; MODEL=lgb for the V3 LightGBM
python src/final_stack.py                                # ~1 min; writes a submission only if the gate passes
```

quoted are from the runs in the tables above.
